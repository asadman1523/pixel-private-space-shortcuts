# PPS 0.1.3

- Restore the native **Add to Home screen** action in the Compose menu used for Private Space apps on newer Pixel Launcher builds.
- Use **PPS** as the app name in all languages. Clarify setup and describe how shortcuts use Android's system authentication when Private Space is locked.

- 修正新版 Pixel Launcher 長按私人空間 App 時，未顯示原生「新增至主畫面」選項的問題。
- 所有語言統一使用 **PPS** 作為 App 名稱。更新設定步驟及模組描述，說明私人空間鎖定時的 Android 系統驗證流程。

Unit tests, debug/release lint and builds, and documentation checks passed. On Launcher 17 (code 907), a signed test build displayed the native **新增至主畫面** action when long-pressing a private app. Adding the shortcut and authenticating from it were not retested in that check.

Pre-release. Version code `9`. Source: [v0.1.3](https://github.com/asadman1523/pixel-private-space-shortcuts/tree/v0.1.3).
