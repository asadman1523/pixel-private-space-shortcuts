# 0.1.2 — Launcher compatibility fix

**Installation change: this release uses a new signing certificate.** Android cannot install it over 0.1.1 or earlier releases, or over the debug test build. Uninstall only the Pixel Private Space Shortcuts module, install this APK, enable the module again in LSPosed, select only `com.google.android.apps.nexuslauncher`, and restart Launcher or reboot. Do not clear Pixel Launcher storage or delete Private Space. Keep the existing Home screen layout.

**安裝注意：本版改用新的簽章金鑰。** 0.1.1 等舊版及 debug 測試版無法直接覆蓋更新。請只解除安裝「私人空間捷徑」模組，再安裝本版，於 LSPosed 重新啟用並只勾選 Pixel Launcher，最後重啟 Launcher 或手機。不要清除 Launcher 資料，也不要刪除私人空間。

## Changes

- Fix module initialization failure on newer Launcher 907 builds where `populateAndShowRows` was removed. This failure left existing private shortcuts gray and unable to request authentication after Launcher restarted.
- Support the native `addSystemShortcuts(List)` menu entrypoint while retaining older supported signatures.
- Keep existing workspace click/authentication hooks active when no supported menu entrypoint is available.
- Improve diagnostics for missing or ambiguous required hooks. Native profile identity, Android authentication, icon badging and workspace storage remain unchanged.

## Verification and status

Experimental pre-release. All 21 unit tests, debug/release lint, debug/release builds and the 19-README documentation check passed. On the inspected API 37 device, the corrected adapter loaded after Launcher restart and the owner confirmed that the reported shortcut problem was resolved. A separate post-fix full-device reboot, repeated authentication/cancellation tests and Compose-only menu paths were not verified. The newly signed release APK has not been device-tested.
