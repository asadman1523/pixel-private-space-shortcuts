# PPS 0.1.4

Version code `10` · Android package `io.github.asadman1523.pps`

PPS now uses a new package name. Android installs it separately from earlier releases. If you used the previous module, disable it in LSPosed, enable the new PPS module for Pixel Launcher only, and restart your phone. You can then uninstall the old module. The shortcut identifiers are unchanged.

The setup page now displays PPS without the previous branding banner. The store description explains the required setup and the independent project's relationship to Pixel Launcher and LSPosed.

PPS 已改用新套件名稱，Android 會將它與舊版分開安裝。若曾使用舊模組，請先在 LSPosed 停用舊版，再啟用新版 PPS，僅勾選 Pixel Launcher，然後重新啟動手機。之後即可解除安裝舊模組。捷徑識別碼沿用原本的值。

設定頁已移除原先的品牌標頭，保留 PPS 名稱。商店描述已說明所需環境，以及 PPS 與相容軟體之間的關係。
